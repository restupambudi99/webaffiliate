# MyJourney — Claude Code

Ikuti `AGENTS.md` di repository ini untuk bahasa, cakupan CMS/kode, workflow editorial, dan perlindungan kredensial. Panduan koneksi ada di `docs/AI-CONNECTIONS.md`.

`.mcp.json` menyediakan `myjourney` (MCP situs dengan OAuth) dan `emdash-docs` (dokumentasi publik, tanpa autentikasi). Setujui konfigurasi proyek bila Claude Code memintanya, lalu gunakan `/mcp` untuk autentikasi dan pemeriksaan status. Membaca file konfigurasi tidak berarti koneksi atau login sudah berhasil.

Gunakan perubahan repository untuk UI/CSS dan alur GitHub/VPS yang sudah ada. Gunakan CMS untuk data yang telah terhubung ke theme. Pertahankan konten serversiderestu/Pinterest milik pemilik dan jangan mengisi persetujuan editorial atau hak media secara otomatis.
